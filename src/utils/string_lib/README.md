# String Library - Funções Bonus da libft

Este diretório contém as funções de lista (bonus) da libft que são necessárias para o minishell funcionar.

## 📁 Arquivos:

- **ft_lstnew.c** - Cria um novo nó da lista
- **ft_lstadd_back.c** - Adiciona um nó no final da lista
- **ft_lstclear.c** - Limpa uma lista inteira
- **ft_lstdelone.c** - Deleta um nó específico
- **ft_lstlast.c** - Retorna o último nó da lista
- **ft_lstsize.c** - Retorna o tamanho da lista

## 📌 Nota:

Estas funções também estão disponíveis na libft principal, mas foram duplicadas aqui em `string_lib` para garantir que estejam sempre disponíveis durante a compilação, independentemente da versão da libft utilizada.
