# ft_printf

Este diretório contém a implementação do ft_printf integrada ao projeto minishell.

## 📁 Estrutura dos Arquivos:

- **ft_printf.c** - Função principal ft_printf()
- **ft_printf_utils.c** - Funções auxiliares do ft_printf
- **get_options.c** - Parser de opções de formatação
- **get_specs_d.c** - Especificações para números decimais
- **get_specs_x.c** - Especificações para hexadecimais
- **write_c.c** - Escrita de caracteres
- **write_d.c** - Escrita de números decimais  
- **write_p.c** - Escrita de ponteiros
- **write_percent.c** - Escrita do símbolo %
- **write_s.c** - Escrita de strings
- **write_u.c** - Escrita de unsigned int
- **write_x.c** - Escrita de hexadecimais

## 📌 Nota:

O ft_printf está disponível no projeto mas atualmente não é utilizado.
O header ft_printf.h está localizado em: `inc/ft_printf.h`
